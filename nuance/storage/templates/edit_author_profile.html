About Custom Pages

Custom pages let you create friendly URLs that display specific posts. This is useful for creating permanent links to important content like "about" pages, contact information, or featured posts.

How it works:

  • Author address profile URL: /authors/dys21abc123/my/path - Always available
  • Author name profile URL: /authors/example.dys/my/path - Always available
  • Optionally, author name URL: example.dys/my/path - Available only if your name, example.dys for example, has nuance.dys set as its destination.
