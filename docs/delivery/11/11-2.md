## Analysis

- **Purpose:** Merge TewQueue and TewChain modules into single queue_chain.py with unified imports and basic structure.
- **Non-functional Considerations:**
  - Security: Maintain all existing validation and verification logic from both modules
  - Performance: Avoid duplicated imports and optimize module loading
  - Observability: Preserve logging and error handling from both systems
- **Business Rules:**
  1. All TewQueue dataclass definitions and factory functions must be preserved
  2. All TewChain TypedDict definitions and validation functions must be preserved
  3. Dyslang compatibility requirements from TewQueue must be maintained

## Addendum: Architecture Simplification (2025-01-02)

The implementation has evolved from the original design. The chain_logic layer has been removed, simplifying the architecture:

### Key Changes:
1. **No chain_logic.py**: There is no separate chain_logic file to merge - all logic is implemented directly in `queue_chain.py`
2. **No StateDict.chain_logic field**: The state schema has been simplified to remove the `chain_logic` field
3. **Direct implementation**: L1 and L2 classes contain the logic directly as methods rather than requiring external callbacks
4. **Simplified imports**: No need to import or manage separate chain_logic code

### Updated Module Structure:
```python
# queue_chain.py (actual implementation)
# ===== TewQueue Components =====
@dataclass
class L1(Queueable):
    def on_message(self, message: Message):
        """Handle L2 messages directly"""
        
@dataclass 
class L2(Queueable):
    def on_message(self, message: Message):
        """Handle L1 messages directly"""

# ===== TewChain Components =====
class StateDict(TypedDict):
    # No chain_logic field
    accounts_by_number: dict[str, Account]
    l1_queue_state: Optional[Dict[str, Any]]  
    l2_queue_state: Optional[Dict[str, Any]]

# ===== Integration Functions =====
def build_next_block(...):
    # Direct method calls instead of callbacks
    l1.on_message(message)
    l2.on_message(message)
```

### Impact on Original Design:
- **Preserved**: All TewQueue dataclasses, TewChain TypedDict definitions, and factory functions
- **Simplified**: No need to merge separate chain_logic implementations
- **Enhanced**: Added safe wrapper functions directly in transaction execution scope

This simplification maintains all the original functionality while reducing complexity and eliminating the need for separate chain_logic code management.
