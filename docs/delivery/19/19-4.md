# 19-4 Add insufficient stake error type with detailed messaging

[Back to task list](./19-tasks.md) | [View Backlog](../backlog.md#user-content-19)

## Analysis
- **Purpose:** Create a specific error type for insufficient stake scenarios with clear, actionable messaging.
- **Non-functional Considerations:**
  - Security: Error messages should not expose sensitive information
  - Performance: Error creation should be lightweight
  - Observability: Error messages should provide clear guidance to users
- **Business Rules:**
  - Error message format: "insufficient stake: have X udys, need Y udys for Z bytes of storage"
  - Must show current stake amount, required stake amount, and storage size
  - Error should be a specific type that can be identified programmatically
  - Should integrate with existing cosmos-sdk error patterns

## Design
- **Technical Specifications:**
  - Create `ErrInsufficientStake` error variable in `x/storage/types/errors.go`
  - Add helper function `NewInsufficientStakeError(have, need math.Int, bytes uint64) error`
  - Use cosmos-sdk error wrapping patterns for consistent error handling
  - Error should include both machine-readable error code and human-readable message
- **Architectural Compliance:**
  - Follows cosmos-sdk error handling conventions
  - Uses consistent error formatting across the module
  - Provides both programmatic and user-friendly error information

## Testing
- **Test Cases:**
  - Error message format is correct with various input values
  - Error can be properly identified and handled by calling code
  - Error message includes all required information (have/need/bytes)
  - Error integrates properly with gRPC status codes
  - Edge cases: zero values, very large numbers
- **Test Data Requirements:**
  - Various stake amounts (have/need) for testing
  - Different storage byte counts
  - Edge cases: 0 stake, 0 bytes, maximum values

## Change Plan
- **Files to Modify:**
  - `x/storage/types/errors.go` - Add ErrInsufficientStake and helper function
- **Implementation Approach:**
  1. Define ErrInsufficientStake error variable with appropriate error code
  2. Create NewInsufficientStakeError helper function with formatted message
  3. Use cosmos-sdk math.Int for precise amount formatting
  4. Add unit tests to verify error message formatting and error type identification
  5. Ensure error is properly exported for use in keeper methods
