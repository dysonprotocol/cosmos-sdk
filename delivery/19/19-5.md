# 19-5 Update StorageMetrics calculation to include min_stake_amount

[Back to task list](./19-tasks.md) | [View Backlog](../backlog.md#user-content-19)

## Analysis
- **Purpose:** Modify existing StorageMetrics calculation logic to compute and include min_stake_amount field.
- **Non-functional Considerations:**
  - Security: Calculation must be deterministic and not manipulable
  - Performance: Calculation should be efficient and not impact query performance significantly
  - Observability: Users can see their required stake in real-time
- **Business Rules:**
  - min_stake_amount = total_bytes × storage_stake_multiple
  - Use cosmos-sdk math.LegacyDec for precise decimal arithmetic
  - Result should be formatted as string representation in udys
  - If storage_stake_multiple = "0", min_stake_amount = "0"
  - If total_bytes = 0, min_stake_amount = "0"

## Design
- **Technical Specifications:**
  - Update existing metrics calculation logic in QueryMetrics and UpdateStorageMetrics
  - Add helper method `CalculateMinStakeAmount(totalBytes uint64, stakeMultiple string) (string, error)`
  - Use cosmos-sdk math.LegacyNewDecFromStr for decimal parsing
  - Use math.NewIntFromUint64 for bytes to decimal conversion
  - Return result as string using .String() method
- **Architectural Compliance:**
  - Integrates with existing metrics calculation patterns
  - Uses cosmos-sdk decimal types for precision
  - Maintains consistency with other amount calculations in the module

## Testing
- **Test Cases:**
  - Correct calculation with typical values (total_bytes=1000, multiple="1.0" → "1000")
  - Zero bytes results in zero stake requirement
  - Zero multiple results in zero stake requirement
  - Fractional multiple calculations (bytes=1000, multiple="0.5" → "500")
  - Large number handling without overflow
  - Invalid decimal string handling
- **Test Data Requirements:**
  - Various total_bytes values: 0, 1, 1000, 1000000
  - Various storage_stake_multiple values: "0", "1.0", "0.5", "2.5", "1000.123"
  - Invalid decimal strings for error testing
