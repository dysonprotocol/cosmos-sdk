# 21-2 Add custom page links display to author profiles

[Back to task list](./21-tasks.md) | [View Backlog](../backlog.md#user-content-21)

## Analysis
- **Purpose:** Display custom page links on author profile pages so visitors can discover the author's additional content
- **Non-functional Considerations:**
  - Performance: Use existing _list_data pattern for efficient pagination
  - Observability: Handle cases where no custom pages exist gracefully
- **Business Rules:** All visitors can view custom page links, but only authorized authors can manage them

## Design
- **Technical Specifications:**
  - Modify `handle_author_posts` function to load and display custom pages
  - Add custom pages section to author profile template
  - Use existing pagination patterns for large numbers of custom pages
- **Architectural Compliance:** Follow existing author profile display patterns and HTMX loading

## Testing
- **Test Cases:**
  - Author profiles display custom page links when they exist
  - Author profiles handle no custom pages gracefully
  - Custom page links navigate to correct URLs
- **Test Data Requirements:** Authors with and without custom pages

## Change Plan
- **Files to Modify:**
  - `nuance/script.py` (modify handle_author_posts function)
  - Author profile templates for display
- **Implementation Approach:**
  1. Update handle_author_posts to query custom pages
  2. Add custom pages section to profile display
  3. Test display with various author configurations
