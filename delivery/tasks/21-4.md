# 21-4 Add routing for custom author pages

[Back to task list](./21-tasks.md) | [View Backlog](../backlog.md#user-content-21)

## Analysis
- **Purpose:** Enable custom author pages to be accessible via `/author_page/<author>/<path>` URLs displaying the referenced posts
- **Non-functional Considerations:**
  - Performance: Use existing post rendering infrastructure
  - Observability: Handle missing pages with proper 404 responses
- **Business Rules:** Custom pages display the linked post content with custom title

## Design
- **Technical Specifications:**
  - Add new route handler for `/author_page/<author>/<path>` pattern
  - Load page data and referenced post for display
  - Use existing post rendering templates with custom title
- **Architectural Compliance:** Follow existing route patterns and HTMX partial loading

## Testing
- **Test Cases:**
  - Custom author pages load and display correct post content
  - Non-existent custom pages return 404
  - HTMX partial loading works correctly
- **Test Data Requirements:** Authors with linked custom pages, various post types

## Change Plan
- **Files to Modify:**
  - `nuance/script.py` (add handle_author_page route)
- **Implementation Approach:**
  1. Add new route decorator and handler function
  2. Load page data and validate existence
  3. Fetch and render referenced post with custom title
  4. Test routing with various author/path combinations
