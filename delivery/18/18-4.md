# 18-4 Add keeper methods for metrics management

[Back to task list](./18-tasks.md) | [View Backlog](../backlog.md#user-content-18)

## Analysis

- **Purpose:** Implement keeper methods to manage storage metrics state, providing clean abstractions for getting and updating metrics data in the storage module.
- **Non-functional Considerations:**
  - Security: Proper validation of address parameters and byte calculations
  - Performance: Efficient state store operations with minimal overhead
  - Observability: Clear error handling and logging for metrics operations
- **Business Rules:**
  - GetStorageMetrics returns current metrics for an address, zero if none exist
  - UpdateStorageMetrics safely modifies metrics with proper validation
  - Metrics state must persist across node restarts
  - Operations must be atomic and consistent with existing keeper patterns

## Design

- **Technical Specifications:**
  - Add `GetStorageMetrics(ctx, owner)` method returning StorageMetrics
  - Add `UpdateStorageMetrics(ctx, owner, byteDelta)` method for atomic updates
  - Use collections.Map for storing metrics keyed by owner address
  - Follow existing keeper method patterns for error handling and validation
- **Architectural Compliance:**
  - Uses Cosmos SDK collections framework like existing storage operations
  - Maintains consistency with existing keeper method signatures
  - Follows module's error handling and context usage patterns

## Testing

- **Test Cases:**
  - GetStorageMetrics returns zero for non-existent addresses
  - GetStorageMetrics returns correct values for existing addresses
  - UpdateStorageMetrics correctly modifies existing metrics
  - UpdateStorageMetrics handles negative deltas appropriately
  - State persists correctly across keeper operations
- **Test Data Requirements:**
  - Multiple test addresses with varying metrics
  - Positive and negative byte delta scenarios

- **Implementation Approach:**
  - Add StorageMetricsMap as collections.Map field to Keeper struct
  - Implement GetStorageMetrics method with proper error handling
  - Implement UpdateStorageMetrics method with validation
  - Ensure proper initialisation in keeper constructor
