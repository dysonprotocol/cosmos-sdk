# 14-2 Test core utility functions

[Back to task list](./14-tasks.md) | [View Backlog](../backlog.md#user-content-14)

## Analysis
- **Purpose:** Ensure all utility functions work correctly with proper edge case handling
- **Non-functional Considerations:**
  - Security: Test input validation and sanitization
  - Performance: Test efficiency of ID generation and parsing
  - Observability: Clear test coverage of all utility functions
- **Business Rules:**
  - All utility functions must have unit tests
  - Test both valid and invalid inputs
  - Verify error handling

## Design
- **Technical Specifications:**
  - Test `get_post_id()`, `get_author_id()`, `get_tag_id()` functions
  - Test `parse_post_id()`, `parse_author_id()` functions
  - Test `sanitize_content()`, `validate_rating()` functions
  - Test `format_timestamp()`, `calculate_score()` functions
- **Architectural Compliance:**
  - Use parameterized tests for multiple input scenarios

## Testing
- **Test Cases:**
  - Valid ID generation and parsing
  - Invalid input handling
  - Edge cases (empty strings, special characters)
  - Boundary conditions for ratings and scores
- **Test Data Requirements:**
  - Various valid and invalid inputs for each function
